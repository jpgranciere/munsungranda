# 🎬 Especial Netflix: Nossa História de Amor ❤️
### Feito com todo o amor do mundo para a minha Munsungranda

Site temático completo no estilo da interface oficial da **Netflix**, responsivo (adaptado para telas de celular), com animação de introdução, som característico ("TUDUM"), catálogo cinematográfico, player de fotos com efeito *Ken Burns* e a trilha sonora **The Platters - Only You, And You Alone**.

## 🚀 Como Testar Localmente (Agora Mesmo)

1. Abra a pasta do projeto:
   `C:\Users\Usuario\.gemini\antigravity\scratch\nosso-amor-netflix`
2. Dê **dois cliques** no arquivo `index.html`.
3. Ele abrirá instantaneamente no seu navegador padrão (Chrome, Edge, Safari, etc.).
4. Clique no perfil **"Munsungranda ❤️"** para ouvir o som "TUDUM" e ver a mágica acontecer!

> 💡 **Dica de Teste:** No computador, aperte `F12` e clique no ícone de celular (Modo Responsivo) para ver exatamente como ela verá na tela do smartphone!

## 🌐 Como Publicar Gratuitamente na Vercel (Passo a Passo)

A Vercel permite hospedar sites estáticos gratuitamente com HTTPS seguro e alta velocidade.

### Método 1: Arrastar e Soltar (O Mais Rápido - 1 Minuto)
1. Acesse **[vercel.com](https://vercel.com)** e crie uma conta gratuita (ou faça login com GitHub/Google).
2. No painel inicial da Vercel (*Dashboard*), clique em **"Add New..."** ➔ **"Project"**.
3. Se você tiver a extensão/ferramenta da Vercel ou criar um repositório no GitHub:
   * Suba a pasta `nosso-amor-netflix` para um repositório seu no GitHub (pode ser privado ou público).
   * Na Vercel, clique em **"Import"** ao lado do seu repositório.
   * Não precisa mudar nenhuma configuração de build (é HTML estático).
   * Clique em **"Deploy"**.
4. Em cerca de 15 a 30 segundos, a Vercel vai gerar um link como:
   `https://nossa-historia-de-amor.vercel.app`

## 📱 Como Criar o QR Code para a Surpresa

Com o link da Vercel em mãos:

1. Acesse um gerador gratuito e sem expiração, como:
   * **[me-qr.com](https://me-qr.com)**
   * **[qr-code-generator.com](https://www.qr-code-generator.com/)**
   * **[qrcode-monkey.com](https://www.qrcode-monkey.com/)** *(Recomendado: permite colocar cor vermelha e ícone de coração ou Netflix no centro)*.
2. Cole o link gerado pela Vercel.
3. Escolha a cor preta ou vermelha escura (`#E50914`).
4. Baixe o QR Code em alta resolução (PNG ou PDF).
5. Você pode imprimir num cartãozinho, colocar numa cartinha com um bilhete:
   > *"Abra a câmera do seu celular e aponte para cá... preparei um filme especial para você."*
